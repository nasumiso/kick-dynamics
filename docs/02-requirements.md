# 02 要求

> 状態：初版（2026-10-18）。本書は要求 ID（US / FR / NFR）の正本です。Phase 1 の受入条件の詳細は [specs/001-kick-prototype/spec.md](../specs/001-kick-prototype/spec.md) を正本とします。

## 1. 位置づけ

本書はプロジェクト全体の要求を Phase 別に整理する。「Phase」列の意味：

- `1`：Phase 1（MVP）に含む
- `1（目標）`：Phase 1 で扱うことを目標とするが、詳細設計の結果で優先度を調整してよい
- `候補`：採否未決定
- `2`〜`5`：該当 Phase 以降

## 2. 用語

| 用語 | 意味 |
|---|---|
| Core | KickDynamics Core（`packages/physics-core`）。描画非依存の物理計算モジュール |
| Lab | KickDynamics Lab（`apps/web`）。ブラウザ上のシミュレータ |
| 接触条件 | ボール上の接触点、足の速度・移動方向・姿勢・角速度など、衝突直前の状態 |
| 有限質量モデル | 足を有限の質量・慣性テンソルを持つ自由剛体として扱う接触モデル |
| 無限質量モデル | 足を、衝突で速度が変わらない外部駆動の境界（動く壁）として扱う比較用モデル |
| 確からしさ | パラメータ値の根拠の種類（定義値、規格値、文献値、実測同定、仮置き、未決定）。定義は [05 §10](05-physics-model.md) |

## 6. 初期 MVP（Phase 1）の範囲

### 6.1 含む

- 有限質量の 3D 剛体足と剛体球の瞬間点接触（反発・摩擦・回転）、および比較用の無限質量モデル
- 重力・空気抗力・マグヌス力・回転減衰（任意）を含む飛翔計算
- 地面でのバウンド。転がり・停止は目標（FR-15）
- ボール・地面・簡易足モデル・カメラの 3D 表示、接触点のポインティング指定、足の条件入力
- 軌道の事前計算と再生（スローモーション・リプレイ）
- 測定値・衝突診断・パラメータの確からしさの表示、結果の出力
- Phase 1 の VER 項目の自動テスト

### 6.2 含まない

- 有限時間接触、変形、接触面積・圧力分布、接触力の時間履歴（Phase 2 以降）
- 足形状に基づく面接触、キック種別の形状による再現（Phase 3）
- 関節拘束、筋力、FEM、高度な空力（Phase 4）
- ゲームモード（Phase 5）
- スマホ最適化、風・大気条件の変更 UI、複数ボール、ゴール・壁などの障害物
- 実測データとの照合を Phase 1 の完了条件にすること（データが入手できれば実施し、未実施なら未実施と明記する）

## 7. 受入条件の概要

Phase 1 の受入条件（AC）の正本は [spec.md](../specs/001-kick-prototype/spec.md) §8。観点は次のとおり。

1. **操作**：接触点・足の条件を入力 → 実行 → 軌道・回転・バウンドの観察 → リプレイ、が一連でできる。
2. **物理**：Phase 1 の VER 項目が自動テストで合格する。
3. **透明性**：パラメータの確からしさと、モデルが未検証であることが UI に表示される。
4. **独立性**：Core が Node 上でテストでき、禁止された依存がないことを検査できる。
5. **配布**：静的ビルドの成果物を静的ホスティングで配信して動作する。
