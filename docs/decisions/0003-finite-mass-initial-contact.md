# ADR-0003: 初期接触モデルに有限質量の 3D 剛体足を採用（無限質量モデルを比較基準に併置）

- Status: Accepted (provisional)
- Date: 2026-10-18
- 関連：[05-physics-model.md](../05-physics-model.md) §5〜§6、§11

## Context

- Phase 1 では、実装と検証が可能な範囲で、足とボールの相互作用の本質（足の反動、偏心衝突による回転、摩擦によるスピン）を捉えたい。
- 足を無限質量の動く壁とするモデルは単純だが、衝突による足の速度変化を表現できず、足の質量・慣性・接触位置の影響を調べられない。
- 有限時間の接触（ばね–ダンパ、変形）は、接触時間や力の時間変化を扱える一方、パラメータが増え、検証の難度が上がる。
- 実際の蹴り脚は関節で拘束されており、どの単純モデルも完全ではない。

## Decision

- Phase 1 の接触モデルは、**有限質量の 3D 剛体の足**（質量・慣性テンソル・姿勢・並進速度・角速度を持つ）と**剛体球のボール**の、**瞬間的な単一点接触**とする。
- 法線方向は Newton の反発係数、接線方向は Coulomb 摩擦とし、衝撃量によって両剛体の並進速度・角速度を更新する。
- **無限質量の動く壁モデル**を、比較・検証用の基準として同じソルバーで切り替えられるようにする。
- 足の「有効衝突質量」に特定の数値を採用しない。足の質量・慣性テンソルは出典と確からしさを付けたパラメータとして扱う（初期は「仮置き」）。

## Consequences

- 良い点：足の反動と偏心衝突による回転を表現できる。無限質量モデルとの比較で、足の質量特性の影響を確認できる。解析解・保存則による実装検証が可能。
- 注意点：
  - 足の質量・慣性テンソルの値に根拠がない（[OQ-02](../research/references-and-open-questions.md)）。
  - 自由剛体の足は関節拘束を持つ実際の脚とは異なる（05 §11）。
  - 接触時間・変形・圧力分布は出力されない。
  - Newton 反発 ＋ Coulomb 摩擦の代数解は、法線と接線が連成する場合にエネルギーの増加などの不整合を起こしうるため、診断で監視する（05 §6.11、§6.13）。

## Alternatives

| 案 | 評価 |
|---|---|
| 無限質量の動く壁のみ | 単純だが足の反動を表現できない。比較基準として併置する |
| 1 次元の有効質量モデル（スカラーの質量比） | 3D の偏心衝突と回転を表現できない。テストの基準式としてのみ使う |
| 最初から有限時間接触（ばね–ダンパ） | パラメータと検証の負担が大きい。Phase 2 で扱う |
| 関節拘束付きの多剛体の脚 | Phase 4 で扱う |
| FEM などの変形モデル | Phase 4 以降の研究課題 |

## 見直し条件

- Phase 1 の検証や実測比較で、点接触剛体モデルの限界が想定より大きいと分かった場合
- Phase 2 / 3 の着手時（[03 §5](../03-roadmap.md)）
