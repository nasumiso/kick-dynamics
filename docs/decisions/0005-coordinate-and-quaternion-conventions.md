# ADR-0005: 座標系と四元数の規約

- Status: Accepted
- Date: 2026-10-18
- 関連：[05-physics-model.md](../05-physics-model.md) §2・§7.1、[04-architecture.md](../04-architecture.md) §6・§8、tasks T0-02

## Context

- 座標系と四元数の規約は、物理モデルの式、テストの期待値、描画用のアダプタのすべてに影響する。後から変えるとコストが大きく、符号の誤りの原因にもなる。
- 描画には Three.js を使う。Three.js は y 軸を上向きとする右手系で、四元数の成分は `x, y, z, w` の順に並ぶ。

## Decision

- **ワールド座標系**：右手系。$+y$ が鉛直上向き、$+x$ が基準となる蹴り出し方向、$+z = \hat{\mathbf x}\times\hat{\mathbf y}$（$+x$ を向いたときの右手側）。地面は $y = 0$。
- **四元数**：
  - 単位四元数で、物体座標 → ワールド座標の回転（能動回転）を表す：$\mathbf v_W = q\otimes\mathbf v_B\otimes q^{*}$。
  - 積は Hamilton の定義に従う。
  - 成分の並びは `[x, y, z, w]`（ベクトル部が先、スカラー部 `w` が最後）。
- **角速度**：ワールド座標で表す。姿勢の時間微分は $\dot q = \tfrac12\,\hat{\boldsymbol\omega}\otimes q$、$\hat{\boldsymbol\omega} = [\omega_x, \omega_y, \omega_z, 0]$。

式の正本は [05](../05-physics-model.md) とする。

## Consequences

- Core と Three.js で座標系と四元数の成分順が一致するため、アダプタでの並べ替えや軸の入れ替えが不要になる。ただし、変換は必ずアダプタを通す（04 §8）。
- 物理の文献で多い z 上向きや、スカラー部が先頭の四元数 `[w, x, y, z]` の式を参照するときは、軸と成分順の読み替えが必要になる。
- テスト VER-M03・VER-M06・VER-F07・VER-F10 で、規約が守られていることを確認する。

## Alternatives

| 案 | 評価 |
|---|---|
| z 上向きの右手系 | 物理・工学の文献では一般的だが、Three.js との間で軸の変換が必要になる。不採用 |
| 四元数の成分順 `[w, x, y, z]` | 物理の教科書でよく使われるが、Three.js と順序が異なり、取り違えの原因になる。不採用 |
| 角速度を物体座標で表す | 剛体の運動方程式（オイラー方程式）とは相性がよいが、外積を使う接触の計算でワールド座標との変換が増える。不採用（必要な箇所で内部的に変換する） |
