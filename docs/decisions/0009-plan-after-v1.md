# ADR-0009: V1 の結果にもとづく次の段階の順序・範囲とパラメータの置き換え

- Status: Accepted
- Date: 2026-11-15
- 関連：[03-roadmap.md](../03-roadmap.md) §3・§5・§8・§9、[06-validation.md](../06-validation.md) §3・§9.4、[05-physics-model.md](../05-physics-model.md) §5.1・§10.2、[V1 検証レポート](../reports/v1-validation-report.md)、[Phase 1 レビュー](../reports/phase1-review.md) §4、specs/002 tasks V3-02、[ADR-0008](0008-model-version.md)

## Context

- V1（文献による妥当性確認、03 §8）で、Phase 1 のモデル（`MODEL_VERSION` `0.1.0`）を本文で確認した文献の値と比べた（V1 検証レポート）。合否は付けていない。
- 主な結果（レポート §0）：
  - VAL-01：球速 / 足速の文献値は 1.10〜1.45 程度の幅を持ち、モデル（1.09）は下端。L-01 の 2 つの量を同時に満たすには、足の見かけの質量 約 1.8 kg と $e \approx 0.74$ が要る（同定）。
  - VAL-02：回転の実測で、モデルの入力に対応づけられるものはなく、比べられない。FEM の計算（L-03）では、摩擦 0 でも回転し、摩擦への依存が頭打ちにならない。
  - VAL-10・VAL-04：$C_L$（P-13）が速さに依存しないため、速く回転の小さいボールで揚力を小さく見積もる。発射装置の軌道（約 30 m/s、$S$ 0.08）で、モデルは 3.3 m（24 %）遠くまで飛ぶ。
  - 感度（V2-06）：出力を強く左右する仮置きは $e$、$m_A$、$C_L$、次に $\kappa$、$C_D$。$\mu$・足の慣性・寸法は、既定の入力ではほぼ効かない。
- Claude Code が案を作り（tasks V3-02）、人間が 7 項目すべてを案のとおり決めた（2026-11-15）。

## Decision

2026-11-15、人間が決定。

1. **TOL-D と対象量**：TOL-D は未決定のまま残す。理由は 06 §3 に書く（文献値どうしの幅がモデルとの差と同じ程度で、不確かさの付いた文献値が少ない）。「精巧さ」を測る対象量は、球速・回転・打ち出し方向・到達距離・曲がりとする。
2. **Phase 2 / 3 の順序**：案 A（Phase 2 の変形・時間発展が先、03 §5）。
3. **Phase 2 の範囲**：点接触のばね（有限時間の接触）と脚のモデルまで。接触領域を持つモデルは Phase 3 に残す。
4. **脚のモデルの前倒し**：足と下腿を足首でつなぐ最小の脚のモデル（レビュー §4.2）を、Phase 4 から Phase 2 へ前倒しする。
5. **空力の更新の時期**：Phase 2 より前に、小さな段階（A1、仮称）として行う。範囲は、$C_L$ に速さ（$Re$）への依存を入れることと、$C_D(Re)$ の表を加えること。回転減衰のモデルの選択を含めるかは A1 の仕様で決める。
6. **検証の重さの基準**：06 §9.4 に、感度にもとづく基準を加える（主な出力への弾性値が約 0.3 以上の機能は独立検証まで。閾値は仮置き）。接地・転がりのモデルは、VAL-05 のデータが手に入るまで精密化しない。
7. **パラメータの置き換え**：
   - $\kappa$（P-03）を 2/3（仮置き）から **0.61**（文献値）に置き換える。根拠は L-09（Barber & Carré 2010）の 4 種類のボールの慣性モーメントの実測から計算した 0.600〜0.626（平均 0.613、$I$ の誤差 ±5 % で ±0.03）。
   - $C_L$（P-13）は A1 の中で置き換える。$C_D$（P-12）は 0.2 のまま（危機より上の文献の幅 0.15〜0.30 の中）。
   - $m_A$（P-04）・$e$（P-07）は仮置きのまま。同定値しかなく、脚のモデルを入れると量の意味が変わるため。

## Consequences

- Lab の既定の $\kappa$ が変わり、同じ入力でも回転と軌道が変わる（2/3 → 0.61 は約 −8.5 %。V2-06 の回転の弾性値 約 −0.5 から、回転は約 4 % 増える見積もり）。Core の式と、同じパラメータに対する Core の結果は変わらないので、ADR-0008 の規則により `MODEL_VERSION` は PATCH を上げて `0.1.1` とする（spec 002 の AC-V08 による記録）。
- V1 検証レポートの数値は `0.1.0` の既定（$\kappa$ = 2/3）での記録として残す。
- 次の作業は A1（空力の更新）。A1 は Core の変更（係数の表の型の追加）を含むので、仕様・VER・独立検証の手順（06 §9）を踏む。
- Phase 2 の範囲が広がる（脚のモデル）。代わりに、接触領域は Phase 3 に残る。
- 回転（VAL-02）は実測と比べられないまま。接触領域を入れても改善を確かめられないことが、範囲を点接触に留めた理由の 1 つ。

## 再検討の条件

- 足の速度・当てた位置・回転がそろった実測（D-01・D-02）が手に入ったとき（Phase 2 の範囲、接触領域の時期）。
- 横に曲がる軌道の実測（D-03）が手に入ったとき（A1 の効果の確認）。
- A1 の仕様の作成で、$C_L$ の速さへの依存を表す文献値が足りないと分かったとき。

## Alternatives

| 案 | 評価 |
|---|---|
| Phase 2 に接触領域まで含める（案 A を案 C 寄りに広げる、レビュー §4.3） | FEM の計算は接触領域の必要性を示すが、回転の実測がないので、改善したかを確かめられない |
| 空力の更新を Phase 2 と並行で行う | 接触とは独立だが、V1 で見つかった最大の軌道の差の原因なので、先に済ませて軌道の比較の土台にする |
| $\kappa$ を仮置きのまま残す | 実測にもとづく値（L-09）があり、仮置きの 2/3 より根拠が強い |
| $m_A$・$e$ を同定値（約 1.8 kg・約 0.74）に置き換える | 同じ文献値に合わせた同定で、検証に使える別の文献値がない。脚のモデルを入れると意味が変わる |
