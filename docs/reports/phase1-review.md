## 3. 評価

### 3.1 良い点

- 因果の向きが守られている。Core にキック種別の補正や軌道の後付けはなく、接触ソルバーは 05 §6.8 の手順どおり。
- 広い入力の範囲で破綻しない（§2 の格子の走査）。
- 出力の桁は、Claude Code の記憶にある実際のキックの値（球速 / 足速は 1.1〜1.3 程度、カーブキックの回転は毎秒 7〜10 回転程度）と大きくは外れていない。**この記憶の値は一次情報で確認していない**。V1 で確認する。

### 3.2 目的（限りなく精巧なキックシミュレータ）に対する弱点

影響が大きいと考える順。

1. **VAL がゼロ**：どの出力が現実からどれだけずれているか分からず、次に精密化するモデルを根拠で選べない。
2. **足が自由な 1.2 kg の直方体であることの影響が大きい**：接触位置 4 cm で球速が約 2 割変わる。直方体が衝突で回って逃げるためで、脚につながった足では起きにくいと考えられる。05 §11 に定性的な注意はあるが、大きさの記録がない。
3. **回転が幾何だけで決まる**：固着の範囲（$\mu = 0.5$ では横ずれ約 57° まで）では、回転は $\mu$ にも $e$ にもよらず、仮置きの $\kappa$ と「剛体の点接触」の仮定で決まる。$\mu = 0$ では回転しない。
4. **空力が粗い**：$C_D$ は定数で抗力危機を表さない。$C_L$ は 4 例にもとづく折れ線。回転減衰は OFF。
5. **検証の労力が周辺に偏った**：転がりは実装 308 行・テスト約 800 行・独立検証 4 巡で、接触ソルバー（205 行）より手厚い。転がりはキックの本質から遠く、係数は仮置き。

## 4. 提案（未決定）

### 4.1 弱点 1：文献による VAL を先に行う

V1 として決定済み（§5）。

### 4.2 弱点 2：足のモデル

- V2-06 の感度解析で大きさを記録し、05 §11 の既知の限界に数値を入れる。
- V2-02 で、文献の球速 / 足速が、有限質量の足と無限質量の足の値の間のどこに来るかを見る。
- モデルの候補：足と下腿の 2 つの剛体を、足首のばねでつなぐ最小の脚のモデル。物理モデルであり、出力の補正ではない。
- 提案：脚のモデルを Phase 4 から Phase 2 の中へ前倒しする。理由は、有限時間の接触（約 10 ms とされる。未確認）の間、足は脚から力を受け続けるので、自由剛体の足では接触中の運動を表せないため。

### 4.3 弱点 3：回転

- **点接触のばね（03 §5 の案 A の最小の形）だけでは、回転は改善しない**：球に対する点接触の法線力は球の中心を通り、摩擦がなければトルクを生まない。平らな剛体の面に対する変形でも、対称性から合力は中心を通る。
- Asai ら（2002、research §4、本文は未確認）の抄録の要約には、摩擦係数がほぼ 0 でもボールが回転する（足のまわりの局所的な変形による）とある。これを再現するには、変形に加えて足の形（有限の大きさ・曲面）が必要、というのが Claude Code の考察（未検証）。
- 提案 1：V1-01 で本文を確認する。確認できれば、Phase 2 を点接触のばねで止めず、接触領域を持つモデル（弾性基礎モデルなどが候補）まで含める。順序は案 A のまま、範囲を案 C 寄りに広げる形。
- 提案 2：$\kappa$（OQ-06）を文献か実測で決める。
- 案 B（剛体の面接触を先）について：剛体の球と滑らかな剛体の面は必ず 1 点で接し、法線は $\mathbf n = -\mathbf d$ のまま。足の形を入れても変わるのは $\mathbf r_A$ と慣性だけで、面接触は変形があって初めて生じる。このため案 B は勧めない。

### 4.4 弱点 4：空力

- $C_D$ を $Re$ の表に、$C_L$ を文献の曲線に置き換え、回転減衰のモデルを 1 つ選ぶ。
- `simulateKick` は関数の係数を受け付けないので、$C_L$ の折れ線と同じ「素のデータの表」を $C_D$ にも加える Core の変更になる（VER と独立検証を伴う）。
- 時期：V2-04 の比較の後。接触とは独立なので、Phase 2 と並行できる。

### 4.5 弱点 5：検証の労力の配分

- 各 Phase の着手時に、感度（V2-06）をもとに機能ごとの検証の重さを決める。主な出力を左右する機能は独立検証まで行い、周辺の機能は VER だけにする。基準を 06 §9.4 に書く。
- 接地・転がりのモデルは、VAL-05 のデータが手に入るまで、これ以上精密化しない。
