## 2. VAL-01：球速 / 足速（V2-02）

再現：`node scripts/literature-validation.mjs 8`

### 2.1 比べる文献値

L-01（Shinkai ら 2008、本文確認）のインステップキック。プロ 2 名、各 2 本。

| 量 | 被験者 A | 被験者 B |
|---|---|---|
| 球速 / 足速 | 1.41 ± 0.08 | 1.39 ± 0.02 |
| 足の速度の減少率 % | 33.7 ± 2.7 | 34.2 ± 1.4 |
| 足の速度（衝突前）m/s | 21.9 ± 0.4 | 24.3 ± 0.1 |

**読み取りの照合**（2026-11-15）：Codex（`gpt-6.1-sol`、`medium`）が、research §2 の記録を見ずに同じ PDF から Table 1 と定義を読み取った。値・条件・定義はすべて一致した。Codex が挙げた曖昧な点と、その扱い：

- 減少率の単位は表に書かれていない。平均値から計算すると 1 − 14.5/21.9 = 33.8 %、1 − 16.0/24.3 = 34.2 % で表の 33.7・34.2 と合うので、衝突前の足の速度に対する百分率と判断した（平均値どうしの比なので、試行ごとの平均とは小さくずれうる）。
- 球速 / 足速の分母（衝突前か後か）は定義文に書かれていない。30.8/21.9 = 1.41、33.8/24.3 = 1.39 で表と合うので、衝突前の足の速度と判断した。
- 速度は「水平・鉛直成分の生の座標から」とあり、側面（矢状面）内の 2 成分の速さと考えられる。左右の成分を含むかは書かれていない。
- 平均の区間の境界（接触の開始・終了のどちらの時刻から 10 ms か）と、接触時間の端のフレームの数え方は書かれていない。
- Codex は表をページ画像ではなく抽出した文字列で確かめた。Claude Code はページ画像で読んだ（V1-01）。

### 2.2 対応づけの仮定

| 文献の量 | モデルの量 | 仮定と限界 |
|---|---|---|
| 足の速度（第 5 中足骨底のマーカー、接触の直前 10 ms の平均） | 接触点での足の速さ $\lvert\mathbf v_A^p\rvert$（入力） | マーカーは接触点そのものではない。足の回転が小さければ、両者の差は小さいと仮定する |
| 足の速度（接触の直後 10 ms の平均） | 衝突直後の足の重心の速さ、または接触点の速さ | どちらにあたるかは決まらないので、両方を示す。文献の値は、接触中と直後にも脚から力を受けた足の速度だが、モデルの足は衝突後に力を受けない |
| ボールの速度（中心、接触の直後 10 ms の平均） | 衝突直後のボールの速さ（初速） | 10 ms の間の空気抵抗による減速は小さいとみなす |
| インステップでの接触 | ボールの真後ろ、足の上の接触位置 (0, 0) | モデルの接触は 1 点で、足は自由な直方体。文献の足は脚につながり、接触中に底屈する（7.0°・10.1°） |

### 2.3 結果

| 構成 | 球速 / 足速 | 足の速度の減少率 %（重心・接触点） | 文献との差（球速 / 足速） |
|---|---|---|---|
| 既定（有限質量 $m_A$ = 1.2 kg、$e$ = 0.5） | 1.09 | 38.6・38.7 | −0.31（文献の約 78 %） |
| 無限質量の足（$e$ = 0.5） | 1.48 | 0（定義により） | +0.08 |

- 既定のパラメータでは、球速 / 足速は文献より約 2 割小さく、足の速度の減少は文献より約 5 ポイント大きい。
- 無限質量の足は、球速 / 足速では文献に近いが、足の速度が衝突で変わらない（文献では約 34 % 減る）。
- 2 つの量を同時に満たす構成は、既定の値の中にない。

**$m_A$ と $e$ を振った幅**（足の上の接触位置 (0, 0)。全表はスクリプトの出力）：

| $m_A$ kg | $e$ = 0.5 | $e$ = 0.7 | $e$ = 0.9 |
|---|---|---|---|
| 1.2 | 1.09・38.6 % | 1.23・43.6 % | 1.38・48.6 % |
| 2 | 1.22・25.9 % | 1.38・29.3 % | 1.54・32.7 % |
| 3 | 1.29・18.4 % | 1.47・20.8 % | 1.64・23.2 % |

（各欄は「球速 / 足速・足の重心の速度の減少率」）

- 1 次元の正面衝突（05 §6.10）で文献の 2 つの量を両方満たす値を逆算すると、$m_A \approx 1.75$〜$1.80$ kg、$e \approx 0.73$〜$0.75$ になる（被験者 B・A）。これは運動量の保存（$m_A \Delta v_A = m_B v_B$）から、足の「見かけの質量」が約 1.8 kg であることを意味する。
- **これは同定で、検証ではない**。同じ文献値に合わせたので、別のデータで確かめるまで、モデルが再現できることの根拠にはならない（06 §5）。比べるための別の文献値（足とボールの速度が両方そろったもの）は、まだ見つかっていない。

**足の上の接触位置の影響**（$m_A$ = 1.2 kg、$e$ = 0.5）：接触位置を重心の真上から 3〜6 cm ずらすと、球速 / 足速は 1.09 から 0.85〜0.96 に下がり、足の接触点の速度の減少率は 47〜55 % に上がる（自由な直方体が衝突で回るため）。文献の足は脚につながっているので、この感度は文献の条件を表していない可能性がある。

### 2.4 分かったこと

1. **既定のパラメータ（$m_A$ = 1.2 kg、$e$ = 0.5、ともに出典なしの仮置き）では、球速 / 足速が L-01 より約 2 割小さい**。ただし、別の文献（L-03 の実験）では 1.10 で、モデルとほぼ同じになる（§2.6）。文献値そのものに幅があるので、「モデルが小さい」とは言い切れない。
2. 自由な剛体の足でも、$m_A$ と $e$ を選べば 2 つの量を同時に合わせられる（約 1.8 kg・約 0.74）。ただし、
   - 1.8 kg は、靴を含む足の質量（P-04 の仮置き 1.2 kg の根拠）より大きい。脚から受ける力の効果が、見かけの質量に入っていると考えられる（05 §11 の「有効衝突質量」）。
   - 0.74 は、足とボールの間の反発係数として妥当かを確かめていない。
   - 自由な直方体のまま見かけの質量を大きくすると、慣性テンソルの扱い（直方体の式のままでよいか）が問題になる。足の上の接触位置への感度（上の段落）も、見かけの質量では表せない可能性がある。
3. この結果は、脚のモデルの前倒し（[Phase 1 レビュー](phase1-review.md) §4.2）と、$m_A$・$e$ の置き換え（V3-02 の判断項目 4・7）の判断材料にする。どちらも、ここでは決めない。

### 2.5 限界

- 文献は被験者 2 名・各 2 本で、ばらつきの見積もりが粗い。
- 足の速度の定義の違い（マーカーの点、10 ms の平均）を補正していない。
- 打ち出し角・方向は文献にないので比べていない（VAL-03 は対象外のまま）。

### 2.6 追記：別の文献の球速 / 足速（V2-03 で入手、2026-11-15）

L-03（Asai ら 2002、本文確認）の実験（大学生 6 名、4500 fps、Table 1）：球速 25.44 ± 0.76 m/s、足（マーカーの点 7）の速度 23.12 ± 1.03 m/s。平均値の比は 25.44/23.12 = **1.10**（論文に比の値は書かれていない。Claude Code が計算した）。

- L-01 の 1.39〜1.41 と大きく違う。違いの候補：足の速度を測った点（L-01 は第 5 中足骨底、L-03 は点 7。点 7 の解剖学的な名前は書かれていない）、速度の求め方（L-01 は 10 ms の平均、L-03 は 5 点の移動平均の後の値で、どの時刻の値かは書かれていない）、キック（L-03 は Methods でインステップ、Fig. 1 の説明ではカーブキック）、被験者（プロと大学生）。どれが主な原因かは、文献から決められない。
- Nunome ら 2012（L-02）の Fig. 5 の代表例は、足 約 20.5 m/s に対してボールの重心が約 30 m/s（図の読み取り）で、比は約 1.45。
- **結論の修正**：球速 / 足速の文献値は 1.10〜1.45 程度の幅を持ち、足の速度の定義に強く依存する。既定のモデル（1.09）は幅の下端にある。§2.3 の「2 つの量を同時に満たす $m_A$・$e$」は L-01 の定義でだけ意味がある。
- 文献値の幅が大きいので、VAL-01 で TOL-D を決めるには、足の速度の定義をモデルの入力（接触点の速度）にそろえたデータが必要（V3-02 の判断項目 1 の材料）。

## 3. VAL-02：回転（V2-03）

再現：`node scripts/literature-validation.mjs 9`

### 3.1 文献

| 文献 | 区分 | 中身 | 比較での扱い |
|---|---|---|---|
| L-08 Whiteside ら 2010（ISBS） | 本文確認 | 回転の**実測**（セミプロ 4 名、Vicon 250 Hz）。カーブ 36.4 ± 5.1 rad/s・球速 19.2 ± 2.1 m/s、ストレート 22.6 ± 4.5 rad/s・22.1 ± 2.9 m/s。回転軸は速度にほぼ垂直（α = 85〜93°） | 足の速度・当てた位置の数値がないので、モデルの入力に対応づけられない。打ち出しのスピンパラメータで範囲を確かめるだけ |
| L-03 Asai ら 2002（Sports Eng.） | 本文確認 | 当てる位置と回転の関係は **FEM の計算**（脚 4.0 kg、足速 25 m/s、μ = 0.4）。回転は実測していない | モデルどうしの比較（参考）。VAL（実測との比較）ではない |

読み取りの照合（2026-11-15）：Codex（`gpt-6.1-sol`、`medium`）が両論文を独立に読み、表の値（L-03 の Table 1・2、L-08 の Table 1）はすべて一致した。Codex が挙げた注意点：

- L-03 の回転の単位「r/s」は、回転か rad かが論文に書かれていない。同じグループの L-04（Carré ら 2005）が同じ表を「rev/s」と書き、本文で「1.9 rev/s (12 rad/s)」と換算しているので、**回転/s と判断した**（二次情報による判断）。抄録の「摩擦 0〜1 で最大 13 rad/s 増える」も、Fig. 6 の読み取りの増加（約 2 回転/s ≈ 13 rad/s）と合う。
- L-03 の Fig. 6 の値は、Codex が図を見られなかったため照合していない（Claude Code の図の読み取りだけ）。
- L-03 の offset distance の向き・基準点は定義されていない。範囲は Methods（±150 mm）と Table 2（±160 mm）で食い違う。
- L-08 の表の回転の「範囲」（3.1–4.7、4.8–6.6）は、見出しの rad/s と合わない（回転/s と見られる）。範囲は使わない。頁は会議録の印字で確認していない。
- L-08 の接触点は「中央線より下・右に当たっているように見えた」という定性的な記述だけ。

### 3.2 対応づけの仮定（L-03 との比較）

- 足は水平に +x へ 25 m/s、ボールの赤道の上で横に当てる。L-03 の offset distance $b$ を、接触点の方位角 $\psi_d$ で $b = R\sin\psi_d$ と対応づける（L-03 の定義がはっきりしないため、仮定）。
- L-03 の脚 4.0 kg を、自由な直方体の足の質量 4.0 kg とみなす場合と、既定の 1.2 kg の場合の両方を示す。慣性テンソルは直方体の式（05 §5.2）。
- $e$ = 0.5（既定）。L-03 の FEM には反発係数の設定はない（ボールは内部の空気を含むシェルのモデル）。

### 3.3 結果

**当てる位置のずれと回転**（μ = 0.4、足速 25 m/s。回転は回転/s）：

| $b$ mm | L-03 FEM：球速・回転 | モデル 4.0 kg：球速・回転 | モデル 1.2 kg：球速・回転 |
|---|---|---|---|
| 0 | 26.0・−1.9 | 33.9・0.0 | 27.6・0.0 |
| 40 | 23.1・4.0 | 31.7・7.2 | 25.9・6.0 |
| 80 | 18.5・10.5 | 24.1・14.5 | 19.7・12.1 |
| 100 | 15.1・14.6 | 15.1・12.2（滑り） | 12.3・9.9（滑り） |
| 120 | 11.2・16.2 | （$b > R$ = 109.8 mm で定義できない） | 同左 |

- モデルの回転は、$b$ = 40〜80 mm で FEM の 1.4〜1.8 倍（4.0 kg）・1.2〜1.5 倍（1.2 kg）。
- FEM の回転は $b \approx 120$ mm（ボールの半径より外）で最大になる（足に幅があるため、と L-03 の本文）。モデルは点接触なので、$b$ が半径に近づくと接触が成り立たなくなる（接触点が真横に近づく）。
- 中心で当てたとき（$b$ = 0）、FEM は −1.9 回転/s の回転を生むが、モデルは 0。

**摩擦係数と回転**（$b$ = 40・80 mm）：

| μ | L-03 FEM（Fig. 6 の読み取り、40・80 mm） | モデル 4.0 kg（40・80 mm） |
|---|---|---|
| 0 | 約 3.3・約 7.2 | 0・0 |
| 0.4 | 約 3.5・約 8.0 | 7.2・14.5 |
| 1.0 | 約 5.3・約 9.4 | 7.2・14.5 |

（FEM の値は Claude Code の図の読み取りで、不確かさは ±0.3 回転/s 程度。Codex の照合なし）

- FEM は摩擦 0 でも回転し（局所的な変形が軸のまわりに力を伝えるため、と L-03 の本文）、摩擦とともに少しずつ増える。モデルは摩擦 0 で回転 0、摩擦が固着に足りる値（40 mm で 0.2 以下、80 mm で 0.2〜0.4）を超えると変わらない。

**実測（L-08）との範囲の確認**：打ち出しのスピンパラメータ $S_0 = R\omega/v$（平均値どうしの比、$R$ = 0.1098 m）は、L-08 のカーブ 0.21、ストレート 0.11。モデル（1.2 kg、上の条件）では $b$ = 40・60・80 mm で 0.16・0.27・0.42、L-03 の FEM では 0.12・0.23・0.39。L-08 のカーブは、モデルでは $b$ が 50 mm 前後に当たる。L-08 は当てた位置を測っていないので、これは範囲が重なることの確認で、比較ではない。

### 3.4 分かったこと

1. **回転の実測で、モデルの入力に対応づけられるもの（足の速度・当てた位置・回転がそろったもの）は見つからなかった**。VAL-02 は「実測と比べられない」。
2. 計算（L-03 の FEM）とモデルの比べで、定性的な違いが 2 つある。いずれも、05 §6.13 の既知の限界（回転は摩擦の衝撃量からだけ生じる、変形・面接触を表さない）の現れ。
   - 摩擦 0 で回転しない（FEM は回転する）。
   - 摩擦への依存が、固着で頭打ちになる（FEM は少しずつ増える）。
3. 量の比べでは、同じ足の質量（4.0 kg）でモデルの回転と球速が FEM より大きい。FEM は足の変形（ヤング率 30 MPa）でエネルギーを失うが、モデルの足は剛体。ただし FEM の回転そのものは実測で確かめられていないので、どちらが現実に近いかは分からない。

### 5.1 方法

### 6.4 分かったこと

1. **VAL-04 は、縦の面内・トップスピン・約 15 m までの 4 本についてだけ、実測と比べられた**。横に曲がる軌道（キックの曲がり）は、比べられる公開データが見つからず「比べられない」。
2. 速い（約 30 m/s）・回転の小さい（$S \approx 0.08$）軌道で、モデルは実測より 3 m 以上遠くまで飛ぶ。原因は、この範囲の $C_L$ が P-13 では小さいこと（V2-04 の §4.4 の 3 と同じ向き）。V2-04 で係数どうしの比較から見えた差が、軌道の差として確かめられた。
3. 20 m/s 以下では、モデルの差は 0.5 m 以内で、確認用の構成の誤差（約 0.3 m）と同じ程度。
4. これは、空力の更新（$C_L$ の $Re$・速度への依存、V3-02 の判断項目 5）の判断材料にする。P-13 は $S$ だけの関数で、速さ（$Re$）への依存を持たない。

### 6.5 限界

- 4 本・1 種類のボール（32 枚パネル）・発射装置で、キックではない。回転はトップスピンだけで、$S$ は 0.08〜0.17。

- 初期の角速度ではなく、時間平均の値を使った。
- 確認用の係数は同じ実験から求められているので、確認用の一致はモデルの検証にならない。
