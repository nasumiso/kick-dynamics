# AGENTS.md（packages/physics-core）

リポジトリ全体のルールはルートの [AGENTS.md](../../AGENTS.md) にある。ここには Physics Core（KickDynamics Core）の変更に固有の観点だけを置く。

## Code Review Rules

PR レビューで、このパッケージの変更について確認する観点。指摘は日本語で書く。

### 重大（P0 として扱う）

- `three`、DOM、WebGL、ブラウザ API、UI フレームワーク、その他の外部パッケージを import している、または `package.json` に `dependencies` を持つ（ルート AGENTS.md のルール 1・9）。
- 物理的根拠のない補正（キック種別ごとのスピン付与、軌道の後付け補正、目標への吸い寄せなど）が入っている（ルール 2）。
- 物理の時間刻みが描画 FPS や再生速度に依存している（ルール 5）。

### 重要（P1 として扱う）

- 座標系・四元数の規約（ADR-0005：y 上向きの右手系、`[x, y, z, w]`、Hamilton 積、物体 → ワールドの能動回転、角速度はワールド座標）と矛盾する式・テスト。
- Core の入出力が SI 単位でない（ルール 4）。
- 想定内の入力エラーやパラメータの範囲外を例外で投げている（`SimResult` のエラー値で返す、04 §6）。NaN・無限大・ゼロ除算の可能性がある縮退条件の見落とし（05 §7.3〜7.5）。
- テストが期待値を実装から写しただけで、解析解・恒等式・保存則などの独立した根拠を持たない。

### 対象外

- 現実のキックでは起こらない極端な値（1e200、1e300 のような物性値・速度・角速度）の組み合わせによる桁あふれ・アンダーフロー。入力と物性値の現実的な範囲は、パイプライン（`simulateKick`、tasks T1.5-01）の入口でまとめて検証する方針で、個々の関数では扱わない（2026-10-18、人間の判断）。0・負・NaN・無限大などの明らかに無効な値は引き続き対象。
