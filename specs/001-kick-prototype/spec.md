# 001 キックプロトタイプ（Phase 1）仕様

> 状態：Draft（2026-10-18）。本書は Phase 1 の受入条件（AC）の正本です。
> 対象：KickDynamics Lab の Phase 1 MVP（物理成熟度 PM-1、UI 成熟度 UM-1〜UM-2、[03 §2](../../docs/03-roadmap.md)）。
> 数式・記号・パラメータは [05-physics-model.md](../../docs/05-physics-model.md)、検証項目は [06-validation.md](../../docs/06-validation.md) を正本とし、本書には複製しません。

## 1. 目的

足とボールの接触条件を指定してキックを実行し、点接触・瞬間衝突・剛体モデルで計算されたボールの初速・回転・軌道・バウンドを、3D 表示と数値で観察できるようにする。モデルの仮定とパラメータの確からしさを利用者が確認できるようにする。

## 2. 範囲

- 含む：[02 §6.1](../../docs/02-requirements.md) の項目。対応する要求は FR-01〜FR-21、NFR-01〜NFR-14。
- 含まない：[02 §6.2](../../docs/02-requirements.md) の項目（有限時間接触、変形、面接触、関節拘束、ゲームモード、スマホ最適化など）。

## 3. 画面構成（候補）

具体的なレイアウトと操作方法は試作で決める（未決定）。商用作品の画面は複製しない。

| 領域 | 内容 |
|---|---|
| 3D ビュー | 地面、ボール、簡易足モデル、接触点マーカー、足の速度方向の矢印、軌道ライン |
| キック入力パネル | 接触点の数値表示、足の速さ・方向・姿勢・角速度、足モデル（有限質量／無限質量） |
| パラメータパネル | 物理パラメータの値・単位・確からしさ・出典、力項の ON/OFF |
| 結果パネル | 測定値、衝突診断、警告、モデルが未検証である旨の表示 |
| 再生コントロール | 再生／一時停止、再生速度、リプレイ |

## 4. 入力

| 入力 | Core に渡す表現（SI） | 表示単位（候補） | 範囲 | 備考 |
|---|---|---|---|---|
| 接触点 | ボール中心 → 接触点の単位ベクトル $\mathbf d$ | 球面座標（度）とクリック位置 | ボール表面 | ポインティング操作（FR-03） |
| 足の速さ | m/s | km/h、m/s | 未決定 | 暫定：足の重心速度の大きさ。定義は OQ-03 |
| 足の移動方向 | 単位ベクトル | 方位角・仰角（度） | 未決定 | FR-05 |
| 足の姿勢 | 法線 $\mathbf n$ まわりの回転角（rad）と足上の接触位置（m） | 度、mm | 未決定 | 接触面の法線は接触点から決まる（05 §6.2）。表現は OQ-03 |
| 足の角速度 | rad/s（ワールド座標） | 度/s または rpm | 既定 0 | 詳細入力として扱うかは未決定（FR-07） |
| 足モデル | `finite-mass` / `kinematic-wall` | — | — | FR-08 |
| 物理パラメータ | 05 §10 の各パラメータ | パラメータごと | 未決定 | 初期値の多くは「仮置き」 |
| 力項の ON/OFF | 抗力、マグヌス力、回転減衰 | — | — | FR-11 |
| 再生速度 | —（Core には渡さない） | 候補：1、0.5、0.25、0.1 倍 | — | FR-16 |

## 5. 出力

- 測定値：初速、打ち出し角（垂直）、打ち出し方向（水平）、スピン量とスピン成分、最高到達点、キャリー、着地点、横ずれ、飛行時間（転がり実装時は総距離）。定義は [05 §9](../../docs/05-physics-model.md)。
- 衝突診断：衝撃量、固着／滑りの別、衝突前後の運動エネルギー（有限質量モデルでは運動量・角運動量も）、衝突後の足の速度・角速度、警告。
- 軌道：時刻・位置・速度・姿勢・角速度の時系列と、イベント（衝突、接地、転がり開始、停止、最大時間到達）。
- 出力ファイル：入力・パラメータ（確からしさを含む）・設定・モデル版数・結果（形式は OQ-19）。

## 6. 振る舞い

1. 起動時：ボールが原点の地面上に静止し、既定のパラメータ（確からしさの表示付き）が読み込まれる。結果パネルに「モデルは未検証」である旨が表示される。
2. 接触点の指定：ボール表面をクリックすると接触点マーカーが表示され、接触面が接触法線と一致するように簡易足モデルが配置される。
3. 足の条件の入力：速度方向の矢印が更新される。接触点で足がボールから離れる向き（$u_n^- \ge 0$）の場合は、実行できない理由を表示する。
4. 実行：Core がキック 1 回分の軌道を終了条件まで事前計算し、再生を開始する。
5. 再生：スローモーション・一時停止・リプレイは再生クロックの操作のみで行い、再計算しない。
6. 再実行：条件を変えて再実行すると、結果が更新される（前回の軌道の重ね描きは候補、FR-22）。

エラー・警告：

- 離反方向の足速度、範囲外のパラメータ、計算不能（05 §6.8 の分母が 0 以下など）は、エラーとして理由を表示し、結果を表示しない。
- エネルギーの増加、滑り方向の反転、マグヌス力の縮退判定、最大時間への到達などは警告として表示し、結果は表示する。

## 7. 制約

- [AGENTS.md](../../AGENTS.md) のルールに従う（Core の独立、物理的根拠のない補正の禁止、SI 単位、時間の分離、依存追加の承認）。
- キック種別ごとの補正を行わない。キック種別名のプリセットを作る場合は入力条件の組としてのみ定義する（FR-23、候補）。
- 衝突前の足の接近アニメーションを表示する場合、それは演出であり物理計算に影響しない。そのことが分かる表示にする。
- 静的ホスティングで動作する。

## 8. 受入条件

「確認方法」の「自動」は自動テスト、「手動」は手動での操作確認、「レビュー」はコードレビュー。

| ID | 条件 | 確認方法 | 関連 |
|---|---|---|---|
| AC-01 | 3D ビューにボール・地面・簡易足モデルが表示され、マウス操作でカメラを回転・ズームできる | 手動 | FR-01, FR-02 |
| AC-02 | ボール表面をクリックすると接触点マーカーが表示され、接触点（$\mathbf d$ と球面座標）が数値で表示される。ボール以外をクリックしても接触点は変わらない | 手動 ＋ 自動（$|\mathbf d| = 1$） | FR-03 |
| AC-03 | 接触点を指定すると、足の接触面法線が接触法線と一致するように足モデルが配置される | 自動（VER-C17）＋ 手動 | FR-06 |
| AC-04 | 足の速さ・方向・姿勢を入力でき、入力値が SI に変換されて Core に渡される | 自動（VER-M05、入力変換のテスト） | FR-04〜FR-07, FR-18 |
| AC-05 | 接触点で足がボールから離れる向きの場合、キックは実行されず理由が表示される | 自動（VER-C13）＋ 手動 | FR-10 |
| AC-06 | キックを実行すると、軌道ライン、ボールの移動と回転、接地とバウンドがアニメーション表示される | 手動 | FR-10, FR-12〜FR-14 |
| AC-07 | 再生速度を切り替えられ、再生速度を変えても計算結果（測定値・軌道データ）は変わらない | 自動（VER-S04）＋ 手動 | FR-16, NFR-04 |
| AC-08 | リプレイで、同じ軌道が最初から再生される | 手動 | FR-16 |
| AC-09 | 測定値が 05 §9 の定義どおりに計算され、内部単位と表示単位を区別して表示される | 自動（VER-S03、VER-M05） | FR-17, FR-18 |
| AC-10 | 足モデルを有限質量／無限質量で切り替えて実行でき、それぞれの結果が表示される | 自動（VER-C12）＋ 手動 | FR-08 |
| AC-11 | 抗力・マグヌス力・回転減衰を個別に ON/OFF でき、すべて OFF のとき軌道が真空中の放物運動の解析解と一致する | 自動（VER-F01）＋ 手動 | FR-11 |
| AC-12 | 衝突診断（衝撃量、固着／滑り、衝突前後の運動エネルギー、警告）が表示される | 手動 ＋ 自動（診断値の計算は VER-C03〜C06、C14） | FR-21 |
| AC-13 | 各物理パラメータの値・単位・確からしさ・出典が UI で確認でき、「仮置き」「未決定」「未検証」の値はそれと分かる表示になる | 手動 | FR-19, NFR-13 |
| AC-14 | 入力・パラメータ・設定・モデル版数・結果をファイルに出力でき、出力された入力・パラメータ・設定で Core を再実行すると同じ結果が得られる | 自動（往復テスト、VER-S01） | FR-20, NFR-05, NFR-06 |
| AC-15 | 06 §6 の Phase 1 の VER 項目がすべて自動テストで合格する | 自動 | NFR-09 |
| AC-16 | Core が Three.js・DOM を参照せず、ブラウザなしの Node 環境でテストが実行できる | 自動（VER-S05） | NFR-03, NFR-12 |
| AC-17 | 静的ビルドの成果物を静的ファイルサーバーで配信し、対象ブラウザで AC-01〜AC-13 の操作ができる | 手動 | NFR-01, NFR-02 |
| AC-18 | Core にキック種別ごとの補正や軌道の後付け補正が存在しない | レビュー | 01 §7 |
| AC-19 | 転がりモデルを実装した場合、ボールが停止した時点で停止イベントが記録され、総距離が表示される | 自動（VER-G03、G04）＋ 手動 | FR-15（目標） |
| AC-20 | 06 §9.4 の独立検証の対象のうち、Phase 1 で実施すると決めた項目について照合結果が記録され、未解決の差異がない（または残っている差異と判断の理由が記録されている） | レビュー | 06 §9 |

精度に関する数値の受入条件（例：実測との誤差 ○% 以内）は設けない。実測データがないため（[06 §5](../../docs/06-validation.md)）。
