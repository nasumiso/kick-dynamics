# 002 文献による妥当性確認（V1）仕様

> 状態：承認済み（2026-11-15、人間が承認、V0-01）。本書は V1（[03 §8](../../docs/03-roadmap.md)）の範囲と受入条件（AC-V）の正本です。
> 検証項目（VAL）の定義は [06 §5](../../docs/06-validation.md)、数式とパラメータは [05](../../docs/05-physics-model.md)、文献と実測データの一覧は [research](../../docs/research/references-and-open-questions.md) を正本とし、本書には複製しません。
> 対象の VAL 項目・確認の区分・受入条件は、V0-01 で確定しました。使う文献は V1-01〜V1-03 で確認できたものに限ります。

## 1. 目的

背景は [Phase 1 レビュー](../../docs/reports/phase1-review.md)（記録）。

Phase 1 のモデル（`MODEL_VERSION` `0.1.0`）の出力が、公開されている実測値からどれだけずれているかを記録する。その結果を、次に精密化するモデルの選択（Phase 2 / 3 の順序、脚のモデルの前倒し、空力の更新）の根拠にする。

## 2. 範囲

- 含む：
  - 文献・公開データの一次情報の確認と、確認した範囲の記録。
  - Phase 1 のモデルと文献値の比較（VAL）と、その記録。
  - 比較と感度解析を再実行できるスクリプト（依存パッケージを追加しない）。
  - Phase 2 の目標値になる量（接触時間・接触力・変形）の文献値の収集。
  - 結果にもとづく判断の記録（ADR）。
- 含まない：
  - 自前の計測。
  - Core のモデルの式の変更、新しい力項・接触モデルの実装。
  - Lab（`apps/web`）の機能の追加。
  - 文献値に合うように係数を調整して「一致した」と報告すること（同定をする場合は、同定に使ったデータと検証に使ったデータを分ける。06 §5）。

## 3. 対象

| VAL | 比べる量 | Phase 1 のモデルで分かっていること（2026-11-15 の掃引、既定のパラメータ） | 比較の難しさ |
|---|---|---|---|
| VAL-01 | 球速 / 足速 | 正面衝突で、有限質量の足は 1.09、無限質量の足は 1.48。足の上の接触位置を幅方向に 4 cm ずらすと球速が約 2 割下がる | 文献の「足の速さ」が足のどの点の速度かを、モデルの $\mathbf v_A^p$ に対応づける必要がある |
| VAL-02 | 回転と、接触のずれ・摩擦係数の関係 | 接触点を 20° ずらすと 436 rpm。固着の範囲では $\mu$ と $e$ によらない。$\mu = 0$ では回転 0 | 文献のずれ（距離）とモデルの $\mathbf d$（角度）、足の向きの対応づけ |
| VAL-10 | $C_D(Re)$、$C_L(S)$ | $C_D$ は定数 0.2（P-12）、$C_L$ は折れ線（P-13）。抗力危機は表さない | 係数どうしの比較で、対応づけは比較的容易。$S$ の定義（05 §7.6）を出典ごとに確認する |
| VAL-04 | 軌道（曲がり・到達距離） | 23〜24 m/s・430〜530 rpm の例で、25 m 先の曲がりは 3.0〜5.5 m | 初速・回転・軌道が同時に記録された公開データが必要。見つからなければ「比べられない」と記録する |

- VAL-03（打ち出し角）は VAL-01 の文献で値が得られた場合に限って比べる。VAL-05（バウンド・転がり）は対象外（キックの本質から遠いため）。
- 掃引の数値は、モデルの挙動の記録であり、文献との比較ではない。

**収集だけを行う量**（Phase 1 のモデルは出力しない）：接触時間（D-04）、接触力（D-05）、変形（D-06）。

## 4. 文献の確認の区分

文献の内容を使うときは、どこまで確認したかを次の区分で記録する（research §2 に書く）。

| 区分 | 意味 | 比較に使えるか |
|---|---|---|
| 本文確認 | 本文（著者版・機関リポジトリの版を含む）で、値・測定条件・定義を確認した | 使える |
| 抄録のみ | 抄録で値を確認した。測定条件や定義の一部は未確認 | 参考として記録する。比較の結論には使わない |
| 二次情報 | 他の文献・解説からの引用 | 使わない（一次情報を探す手がかりにする） |

- 図から値を読み取った場合は、読み取りであることと読み取りの不確かさを書く。
- 本文を入手できない文献は、入手できないことを記録する（値を推測で埋めない）。
- 文献の候補は research §4。2026-11-15 に検索で見つけた候補は、書誌の一部だけを確認した状態（未確認）。

## 5. 比較の方法

1. 文献の測定条件（ボール、速度域、キックの種類、被験者、測定した点）を、モデルの入力（05 §6.2）へ対応づける。対応づけに置いた仮定を記録する。
2. 対応づけられない条件（脚の拘束、足首の角度など、モデルにない量）は、モデルの限界として記録する。入力を調整して一致させない。
3. 文献で特定できないモデルのパラメータ（$e$、$\mu$、足の質量など）は、仮置きの値での結果に加えて、範囲を振ったときの結果の幅を示す。
4. 結果は「文献値、モデルの値、差、文献の不確かさ、対応づけの仮定」の組で記録する。合否は付けない（TOL-D が未決定のため）。
