### [x] U1-03 打点パッドと結線
- 担当：Claude Code
- 内容：SVG と Pointer Events で打点パッドを作り、3D ビューの右下に重ねる。数値入力（`createKickPanel` に値の反映を足す）と同期させる。3D クリックで方向を寄せたときの表示。
- 依存：U1-01、U1-02
- 完了確認：AC-U01、AC-U04〜AC-U06 を手動で確認（画面を撮って記録）。
- 結果（2026-11-21）：`src/ui/hit-pad.ts`（SVG の打点パッドと知らせ）、`createKickPanel` に `setValues`、`main.ts` の結線（数値入力の ψ・θ も `limitDirection` を通す）。`contact-picker` で、ドラッグで終わった押下の位置が残る点を直した。
  - 手動の確認（ヘッドレスの Chrome を DevTools Protocol で操作して画面を撮った。Claude in Chrome は未接続だった）：
    - AC-U01：打点パッドのドラッグで、接触点・足・矢印が追従した（$\mathbf d$ = (−1, 0, 0) → (−0.441, 0.236, 0.866)）。
    - AC-U04：矢印の先端のドラッグで ψ 0° → −13°、θ 10° → 35° に変わり、$\mathbf d$ は変わらなかった。数値入力で ψ = 150° を求めると、範囲の端の −7° で止まり、入力は有効のままだった。円弧の範囲外の部分が灰色で描かれた。
    - AC-U05：上の操作のたびに、数値入力の ψ・θ と打点パッドの表示が一致した。
    - AC-U06：3D クリックで方向を寄せる場面は、ヘッドレスでは確認できていない（クリックした位置が方位の円弧の掴む範囲に入り、ハンドルが優先された）。関数はテストで確認済み。
  - 気づいた点：方位の円弧がボールの上に重なる視点では、その部分のボールのクリックより円弧の操作が優先される。
  - 改訂（2026-11-21、ユーザーの指摘「ギズモの動きがよくわからない」「リングは回すもの」）：最初の版は、方位の円を先端の高さの小円にし、ドラッグを「マウスの光線とリングの面の交点」で読んでいた（斜めから見ると値が飛ぶ）。3D ツールの回転ギズモにならって作り直した：接触点を中心とする大円を画面上で一定の大きさに描き、回転量は掴んだ点での接線方向のマウスの動きで決める。リングは動かさず、今の角度の目印がリングに沿って動く。ドラッグ中は掴んでいないリングを薄くする。先端のドラッグは画面上の微分を使う減衰付き最小二乗にした。
    - 確認（既定の視点、ヘッドレスの Chrome）：方位のリングを接線方向に 60 px → ψ 0° → 40°（期待 40.4°）、垂直方向に 60 px → ψ 1°、逆向きに 200 px → −72° の端で停止。仰角のリングを接線方向に 40 px → θ 10° → 37°（期待 37°）、200 px → 60° で停止。ドラッグ中の画面で、リングが動かず目印だけが回ることを確認した。
  - 改訂（2026-11-21、ユーザーの指示）：打点パッドを、足の移動方向から見た図から、その水平成分の向きからボールを水平に見た図に変えた（spec §3）。選べる範囲は θ によって形が変わるので、輪郭を描いて外側を灰色にし、外側は中心からの向きに沿って端へ寄せる（`selectableHit`、`maxHitRadius`、`clampHitToRange`）。
    - 確認：初期の打点がパッドの中心。θ = 35° で上側が灰色になり、上へドラッグすると上 66 mm（範囲の端）で止まり、入力は有効のまま。右下へのドラッグは反映された。ψ を変えても $\mathbf d$ は変わらなかった。
  - 追加（2026-11-21、ユーザーの指示）：足の移動方向の水平成分の真後ろから見る視点（V キーと表示パネルのボタン、`src/render/camera-presets.ts`）。最初の配置（後ろ 1.1 m・上 0.35 m）では足の直方体がボールに重なったので、後ろ 1.3 m・上 0.75 m・注視点 1.5 m 前にした。ψ = 0°・30° で V を押し、真後ろからの視点になることを画面で確認した。
  - 改訂（2026-11-21、ユーザーの指摘「水平ギズモを回すと 2D の打点が動く。3D で打点は動かないのだから 2D でも動かない」）：打点パッドの視点を、足の移動方向の水平成分からカメラの水平の向きに変えた。灰色の部分は画素ごとに判定して描く（形が円にならないため）。接触点が裏側のときは白抜きで示す。
    - 確認：V の視点で緑のリングを回し、ψ 0° → 25° → −26° でパッドの打点が中心のまま変わらず、灰色の部分だけが変わることを画面で確認した。
  - 改訂（2026-11-21、ユーザーの指摘「カメラを回す中心がボールでなくなった」）：足の後ろから見る視点で注視点をボールの前に置いていたため、カメラの回転の中心がずれていた。注視点をボールの中心に戻し、配置を後ろ 1.4 m・上 0.5 m にした。V の後にカメラを回してもボールが画面の中心に残ることを確認した。
