> 状態：**完了**（2026-11-25、A4-02）。承認（2026-11-22、人間、A0-01。§7 はすべて Claude Code の案のとおり決定。§7.1 は A1-01 で追加）。本書は A1（[03 §3](../../docs/03-roadmap.md)）の範囲と受入条件（AC-A）の正本です。
> 数式・パラメータの正本は [05](../../docs/05-physics-model.md)（§7.3〜7.6、§10.2）、検証項目は [06](../../docs/06-validation.md)、文献は [research §2.2](../../docs/research/references-and-open-questions.md) です。本書には式を複製せず、変更の方針だけを書きます。05・06 は A1-02 で更新します。位置づけは [ADR-0009](../../docs/decisions/0009-plan-after-v1.md) の決定 5・7。

## 1. 目的

V1 で見つかった、軌道の最大の差の原因を取り除く。

- **揚力**：$C_L$（P-13）は $S$ だけの関数で、速さ（$Re$）に依存しない。そのため、速く回転の小さいボールの揚力を小さく見積もる。発射装置の約 30 m/s・$S$ 0.08 の軌道で、モデルは 3.3 m（24 %）遠くまで飛ぶ（[V1 レポート](../../docs/reports/v1-validation-report.md) §6）。
- **抗力**：$C_D$（P-12）は定数 0.2 で、抗力危機を表さない。約 12.5〜15 m/s 未満（短いパス、高いキックの頂点の付近）で文献から外れる（V1 レポート §4.4）。

## 2. 範囲

- **含む**：
  - $C_D$ を $(Re, S)$ の表で与えるモデル（05 §7.3 の「$Re$ などの関数として差し替え可能」を、境界を越えて渡せる素のデータで実現する）。回転による $C_D$ の増加を含む（A1-01 で範囲に追加、2026-11-22、人間が決定。L-10 の Fig. 8）。
  - $C_L$ を $(Re, S)$ の表で与えるモデル（05 §7.4 の $S$ の折れ線の拡張）。
  - 表の値の根拠になる文献の確認と、値の決定（P-12・P-13 の置き換え）。
  - VER の追加、独立検証（06 §9。V1 の感度で $C_L$ の弾性値が大きいため、06 §9.4 の基準で必須）。
  - V1 の比較（VAL-04・VAL-10）のやり直しと記録。
  - Lab のパラメータ表示（表の値・出典・確からしさ）。
- **含まない**：
  - 揚力の危機、抗力危機のヒステリシス、無回転ボールの不規則な挙動（05 §7.8、Phase 4）。
  - 風・大気条件の変更。
  - $S$ の定義（$\lvert\boldsymbol\omega\rvert$ か $\lvert\boldsymbol\omega_\perp\rvert$ か、OQ-07）の決定。文献がすべて回転軸が速度に垂直な条件で、決められない（V1 レポート §4.4）。現在の暫定（$\lvert\boldsymbol\omega\rvert$）のままにする。
  - 回転減衰のモデルの選択（A0-01 で決定：含めない。Lab の既定は「なし」のまま）。
  - キックの接触モデル（Phase 2）。

## 3. モデルの形（案）

05 §7.3・§7.4 の式（力の形、縮退の規則）は変えない。係数の与え方だけを足す。

| 係数 | 形（案） | 補間・範囲外 | 根拠 |
|---|---|---|---|
| $C_D$ | $Re$ の格子 × $S$ の格子の表 $C_D(Re_j, S_k)$（$C_L$ と同じ型） | 双線形補間。表の範囲外は端の値（外挿しない） | 抗力危機は $Re$ の狭い範囲での急な変化として表す。回転による増加（L-10 Fig. 8）を $S$ の方向で表す（A1-01 で決定） |
| $C_L$ | $Re$ の格子 × $S$ の格子の表 $C_L(Re_j, S_k)$ | $Re$・$S$ の両方向に線形補間（双線形）。範囲外は端の値。$S = 0$ の列は 0 | 文献の値が「$Re$（速さ）ごとの $C_L(S)$」の形で与えられるため。$C_L(Re, 0) = 0$ で、05 §7.4 の定数 $C_L$ の制約（$\boldsymbol\omega \to \mathbf 0$ で不連続）を避ける |

- どちらも関数を含まない素のデータで、一括計算（`simulateKick`）の境界を越えて渡せる（[04 §9](../../docs/04-architecture.md)）。
- 既存の係数の形（定数、$S$ の折れ線、関数）は残す。VER と比較のため。
- 表の検証（空、有限でない値、格子が狭義単調増加でない、$C_D < 0$、$S$ の最初の点が 0 でないなど）は、積分の前に `invalid-coefficient` を返す（05 §7.4 の $S$ の折れ線と同じ方針）。
- **$Re$ の定義**：表は、モデルの $Re = \rho\lvert\mathbf v_r\rvert(2R)/\eta$（05 §7.6）で引く。文献の値は、文献ごとの $Re$（動粘性係数が異なる）ではなく、**速さ**を介してモデルの $Re$ に換算して表にする（V1 レポート §4.2 の対応づけと同じ）。
- **$\eta$（P-11）**：これまで一括計算では使っていなかった（04 §6）。$Re$ の表を使う場合は使う。

## 5. 検証

- **VER（案。番号と許容誤差は A1-02 で 06 に書く）**：
  - $C_D(Re)$ の表：節点の値、節点の間の線形補間、範囲外で端の値、無効な表で `invalid-coefficient`。抗力の大きさが $\tfrac12\rho A C_D(Re)\lvert\mathbf v_r\rvert^2$。
  - $C_L(Re, S)$ の表：格子点の値、双線形補間、範囲外で端の値、$S \to 0$ で力が連続に 0。無効な表で `invalid-coefficient`。
  - 既存の VER-F03（抗力による散逸）・F05（マグヌス力は仕事をしない）・F06（縮退）・F07（鏡映）を、新しい形でも満たす。F05 は速さが一定なので $Re$ も一定で、円運動の半径の解析解がそのまま使える。
  - 時間刻みの収束（VER-F02 の方法）：表の折れ目をまたぐ軌道で、収束の次数が下がるかを確かめて記録する（折れ線は 1 階微分が不連続）。
- **独立検証**：IV-07（新設、案）。対象は表の形の係数の評価と、力・縮退の規則との組み合わせ（05 §7.3〜7.6）。手順は 06 §9.2。Claude Code は照合が終わるまで `verification/independent/` を読まない。
- **VAL**：VAL-04（L-06 の 4 本）と VAL-10（係数どうし）を、新しい既定でやり直し、V1 の結果と並べて記録する。§4 の同定と検証の分離に従う。
