## 移行と滑りの独立期待値

前提は水平静止地面、等方剛体球、`n=+y`、`r=−Rn`。D §1〜3の剛体運動学とNewton–Euler方程式から、

- 接触点速度は `u=(vx+Rωz,0,vz−Rωx)`。
- 滑り中は `dv/dt=−μ_g g û`、`dω/dt=μ_g g(n×û)/(κR)`。
- `du/dt=−μ_g g(1+1/κ)û`。
- `v+κR(ω×n)` とωyは一定。
- 散逸率は `dE/dt=−μ_g m g|u|`。

したがって+x方向の滑りならωzは減少する。強いトップスピンでは摩擦が重心を加速しても、接触点の滑りと全エネルギーは減る。この符号を実装の成分式 `(ûz,0,−ûx)` に照合した。

移行の独立合成例を `m=R=1,κ=2/5,μ_g=1/5,e_g=1/2,g=10,Δt=1/10,vrest=1` とする。`e_g vrest=gΔt/2` の等号を満たし、位置y=1、入射 `v=(1,−1,0),ω=(0,7,0)` は移行条件の等号である。非反発衝突では、

`jn=1, Jt=(−1/5,0,0), v+=(4/5,0,0), ω+=(0,7,−1/2)`

となる。固着必要量2/7に対して摩擦上限1/5なので滑りが残る。通常反発e_g=1/2で先に解くと接線衝撃は−2/7となり異なる。`groundHandler` は移行判定の後にrestitutionを0へ置き換えてsolverを呼ぶので、前者と一致する構成である。これはソルバーを期待値として再呼び出すG06テストの循環を補う独立期待値である。ソルバー自体は今回の許可ソース外なので再調査していない。

`e_g=0` では閾値を超える入射も同じ非反発衝突へ進む。開始時vy=0では衝撃自体はseparatingで、接線状態を保って接地拘束へ入り、その後に滑りを解く。正の離反速度は飛翔側の開始接地処理の対象にならない。

Dの滑り例の合成値 `m=R=1,κ=2/5,g=10,μ_g=1/5` に対する独立期待値は次のとおり。位置欄は初期位置からの変位である。

## 純転がり・静止・停止イベントの区別

D §4.2の拘束付き運動方程式では、必要な静止摩擦は進行方向を向き、大きさは `κμ_r mg/(1+κ)`。接触点で仕事をせず、重心抵抗の仕事が全散逸になる：

`E−Iωy²/2=(1+κ)mV²/2`、`dE/dt=−μ_r mgV`。

DのR05は `m=R=1,κ=2/5,g=10,μ_r=7/50,V₀=5,ωy=0`。独立期待値は減速度1、物理的停止時刻5、変位25/2、散逸35/2（各SI単位）。R01を先行させたR06は全時刻6、全変位37/2、全散逸49/2。R07の `vstop=1/10,ωstop=1/5` では境界時刻49/10、その位置2499/200であり、境界そのものでは停止述語は偽である。実装の区間時間・位置の二次式・水平角速度拘束はこの解に一致する。

**物理的な並進停止**では水平速度と水平回転を0にする。一方、**閾値によるstopイベント**は述語が真になった状態を記録して終了するため、一般には小さな非零速度が残る。実装はイベント時にこれを0へ書き換えていない。仕様はこの書き換えを要求していない。

ωyだけを残すという規則は、停止判定でωyを無視する意味ではない。`isStopped` は全角速度のノルムを用いる。純転がりの停止条件は、`|ωy|<ωstop` のとき

`V < min(vstop, R sqrt(ωstop²−ωy²))`

となる。`|ωy|≥ωstop` なら、並進が0でも述語は偽である。等号でも偽であり、stopなし・総距離nullで最大時間に達する構成になる。ωyが非零でも閾値より小さければstopは可能なので、「ωy≠0なら必ず止まらない」と一般化しない。同様にμ_r=0でも、初めから閾値内ならstopは可能である。

### 格子時刻と残時間の静的追跡

丸めで厳密境界を曖昧にしない補助例として、二進で正確に表現できる合成値 `m=R=κ=1,g=8,μ_g=μ_r=1/4,e_g=1/2,vrest=2,Δt=1/4` を使う。減速度は1で、両方の係数条件を満たす。姿勢は単位四元数、ωy=0、水平移動は+x方向とする。

## パラメータ・極限・仕様自体の確認

- `κμ_r/(1+κ)=μ_g` は拒否条件の厳密な `>` に入らず許可される。例えばκ=1、μ_r=1/2、μ_g=1/4は等号。超過だけを拒否する現在のPhase 1決定に一致する。Dの「上限超過後の再滑りのモデルは未定」という論点を、現在は入力範囲外とすることで処理している。
- `e_g vrest=gΔt/2` も許可される。保持されるバウンドは入射速度b>vrestなので、重力のみなら滞空時間 `2e_g b/g>Δt`。y=Rへの射影も現在の許可仕様・実装にある。D §5.3の旧「位置を戻さない」反例を、そのまま現実装の不一致として扱わない。
- このバウンド時間条件は重力のみの十分条件であり、空力・積分誤差を含む一般保証ではない。今回の「転がりの間は空力を無視」と、飛翔中の空力を無視する仮定は区別する。
- e_g=0では常に移行し、上記のe_g>0専用検査を行わない。μ_g=0では有効な係数範囲上μ_r=0となり、初期滑りは消えない。実装はslideTime/rollTimeをInfinityとしてゼロ除算を避ける。μ_r=0の純転がりは一定速度。初期u=0ではuによる正規化を避ける。duration=0は状態をそのまま返す。
- 係数検証は負値・非有限、e_gの範囲、正のg、正の停止閾値を検査する。restSpeedと接線閾値は有限かつ非負を許す。通常の計算は検証済み `groundHandler` が組み立てるrollingモデルを使う。`advanceRolling` 単体は有効な物性・係数とy=R・vy=0を満たす入力を前提とする。
- 次元は `u,vrest,vstop` がm/s、ωstopがrad/s、滑り減少率と減速度がm/s²、角加速度がrad/s²。摩擦限界式は無次元、`e_g vrest` と `gΔt/2` はともにm/s。並進加速度からmとRが消えても、角加速度には1/Rが残り整合する。
- 水平面内の回転、水平並進、球姿勢の変更で力学的な予測は変わらない。水平90度回転の独立算術でも位置・速度・角速度が同じ回転で写ることを確認した。μ→0、u→0、V→0の分岐は独立導出の極限に整合する。
- 2026-10-19に決定された「転がり中は空力なし」「滑り中は動摩擦だけ」を今回の仕様として扱う。D作成時に未定だった別モデルを要求して不一致にはしない。

姿勢は区間ごとに一次のω(t)を与えてRK4を組み、正規化する構成だった。位置・速度・角速度の閉形式とは誤差の種類が異なる。今回、許可範囲外の四元数ヘルパーや積分器の再検証、姿勢誤差の収束実験はしていない。姿勢は等方球の力学へ戻らないため、この制約を並進のTOL-A評価に混ぜない。

## テストの期待値と総距離

既存のrollingテストは、接触点速度0、接触点まわりの角運動量、無回転滑りの終速v₀/(1+κ)、動摩擦の仕事、転がり抵抗の仕事、停止距離v₀²/(2a)を使う。このうち終速・保存量・仕事はD §3〜4から独立に導ける。期待値が物理的根拠を持つことを確認した。

減速度のテスト式だけを根拠に減速度を承認せず、拘束付きの運動方程式と全エネルギーの仕事から係数1/(1+κ)を再確認した。移行のテストは同じbounce関数を期待値として使うため、それだけでソルバーを独立確認したとは言わない。前述の分数例で、通常反発を先に使う誤った接続と区別した。

`totalDistance` はstopイベントのsampleIndexの位置と初期サンプルの位置の水平距離を使う。停止前に方向が逆転する例でも累積移動距離にはしない。例えば初期水平座標(1,−2)、stop位置(4,2)なら期待値5m。stopがない場合はmax-timeの位置から代用品を作らずnullとなる。ωyが閾値以上で残る例、μ_r=0で速度が閾値外に残る例は、このnullの条件を満たす。既存テストにも両方のmax-time/null確認がある。

## 独立算術の完全再現

  const cases=[
    [[7,0,0],[0,0,0],1,[5,0,0],[0,0,-5],[6,0,0],1],
    [[0,0,0],[0,0,-7],1,[2,0,0],[0,0,-2],[1,0,0],1],
    [[1,0,0],[0,0,3],4/7,[-1/7,0,0],[0,0,1/7],
      [12/49,0,0],4/7],
    [[1,0,0],[0,0,3],.5,[0,0,0],[0,0,.5],[.25,0,0],4/7],
    [[3,0,4],[0,7,0],5/7,[15/7,0,20/7],[20/7,7,-15/7],
      [90/49,0,120/49],5/7]
  ];
  const E=(v,w)=>.5*v.reduce((s,x)=>s+x*x,0)
    +.5*k*w.reduce((s,x)=>s+x*x,0);
  for(const [v,w,t,ev,ew,ex,ets] of cases){
    const z=slip(v,w,t);
    near(z.v,ev);near(z.w,ew);near(z.x,ex);near(z.ts,ets);
    const U=Math.hypot(v[0]+w[2],v[2]-w[0]);
    const h=Math.min(t,z.ts),D=mu*g*(1+1/k);
    near(E(z.v,z.w)-E(v,w),-mu*g*(U*h-.5*D*h*h));
    near([z.v[0]-k*z.w[2],z.v[2]+k*z.w[0]],
         [v[0]-k*w[2],v[2]+k*w[0]]);
  }
  const Q=([x,y,z])=>[-z,y,x],a0=[3,0,4],b0=[0,7,0];
  const z=slip(a0,b0,.25),zq=slip(Q(a0),Q(b0),.25);
  near(zq.v,Q(z.v));near(zq.w,Q(z.w));near(zq.x,Q(z.x));

  const a=(7/50)*g/(1+k);
  near(a,1);near(5/a,5);near(25/(2*a),25/2);
  near(1+5/a,6);near(6+25/(2*a),37/2);
  near((5-.1)/a,49/10);
  near(5*4.9-.5*a*4.9**2,2499/200);

  const stopped=(v,w,sv,sw)=>
    Math.hypot(...v)<sv&&Math.hypot(...w)<sw;
  if(stopped([.5,0,0],[0,0,-.5],.5,1))
    throw Error('strict boundary');
  if(!stopped([.25,0,0],[0,0,-.25],.5,1))
    throw Error('next grid');
  if(stopped([0,0,0],[0,1,0],.5,1))
    throw Error('vertical spin boundary');

  near(.5*.125-.5*.125**2+.5*.125,15/128);
  near(.5*.25+(.5*.25-.5*.25**2),7/32);
  near(Math.hypot(3,4),5);
  return {
    maxResidual,cases:cases.length,
    gridStop:.75,midstepStop:.25,endContactStop:.5
  };
})());
