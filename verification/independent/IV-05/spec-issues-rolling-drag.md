# IV-05-D3 仕様修正用の問題一覧（8件）

対象コミット：`3f06545`。対象は 2026-11-14 改定の 05 §8.2 と関連する仕様記述。

独立導出資料で列挙した I-01〜I-08 について、照合前に仕様を検討するための問題点と修正の方向だけを記載する。導出した期待値、閉形式の結果、数値例の値、VER-G07〜G10 の期待値そのものは記載しない。具体例は状態・条件の構成だけで示す。問題番号は元の資料と対応する。

## I-01：滑り消失の内積判定は一般の二次元で十分条件にならない

**対象**：05 §8.2「滑り → 純転がり」。対象記述は「ステップの開始時の向きに対して逆転した」と、切り替え時に水平角速度を拘束から定める処理。

**区分**：誤り、および処理順序の曖昧さ。

**問題と理由**：初期の接触点速度との内積が非正になったことは、その初期方向への射影が非正になったことを意味する。接触点速度ベクトル自体の消失を意味しない。水平二次元では方向が回転し、滑りが残ったまま初期方向と直交する場合がある。純転がりの定義は接触点速度の消失であり、射影の符号だけではこの定義を満たせない。

構成例は、水平速度と接触点速度が平行でなく、摩擦と重心に働く抵抗によって接触点速度の方向が変わる滑り状態である。静止摩擦の上限条件を満たす状態でも、この幾何学的な問題は残る。水平角速度を拘束へ射影すると、残っていた滑りを人為的に消すことになる。

また、拘束へ射影してから境目の条件を確認するのか、確認に合格したときだけ射影するのかが明確でない。前者では、移行を認めない場合にも元の滑り状態を失う可能性がある。

**修正の方向**：

- 方向が固定される一次元の判定と、一般の水平二次元の判定を分ける。
- 二次元では滑りの大きさそのものに対する判定・誤差制御を定め、初期方向との内積だけで切り替えない。
- 数値上の射影を採用するなら、残留滑りと射影による角運動量・エネルギーの変化を管理する。許容幅は根拠を示して別途決定する。
- 移行可否を未射影の状態で確認し、移行を認める場合だけ拘束へ射影する、と処理順序を明記する。

## I-02：二分法の前提となるイベント評価と区間の保証が不足

**対象**：05 §8.2「積分」。対象記述は「部分刻みで積分し直す二分法」と、状態ごとの RK4 積分。

**区分**：曖昧さ、および検出保証の不足。

**問題と理由**：二分法には、対象イベントを含む適切な区間と、その区間で定義されたイベント関数が必要となる。二分法を指定するだけでは、最初のイベントを挟む区間の発見は保証されない。

構成例として、速さに依存する抗力係数が特定の速度帯でだけ大きい場合、一ステップの途中で純転がり維持条件が破れ、ステップ終了前に再び成立することがある。両端だけの検査では内部の破れを見落とす。

また、RK4 の途中の評価点が停止点や滑り消失点を越える場合、速度方向や滑り方向の正規化が未定義になったり、抵抗方向が段内で反転したりする。元の状態の式をそのまま使った積分結果が、イベント探索に適した連続な延長になるとは限らない。段内での反転が相殺され、端点には符号変化が現れない構成もある。

**修正の方向**：

- イベントを越えて旧状態の式を評価する際の定義と、ゼロベクトルの扱いを明記する。
- 単一通過を保証できる係数・刻みの制約を設けるか、内部点検査や区間分割で最初の通過を探す。
- 保証しないケースは適用限界として明記する。二分法の打ち切り幅と、イベントの検出可能性は分けて扱う。

## I-03：低速での力の打ち切りと静止への切り替えが整合していない

**対象**：05 §7.3 の「ゼロ速度」、§8.2 の「純転がり → 静止」、§10.2 の P-23、および 06 の VER-G07 に関係する適用範囲。

**区分**：矛盾。

**問題と理由**：仕様は正の低速閾値以下で抗力と転がり抵抗をともにゼロとする。一方、静止への切り替えは水平速度の反転を用いる。この二つを文字どおり併用すると、低速域で減速させる力がなくなった非ゼロの純転がり状態を、静止へ切り替えられない。

構成例は、純転がりのまま減速し、非ゼロの速さで力の打ち切り域に入る状態である。この域では拘束を保つための静止摩擦も不要であり、力の打ち切りだけでは速度をゼロにできない。向きの正規化を避けるための処理と、状態を静止へ移す処理は別の定義である。

**修正の方向**：

- 力の打ち切りとは別に、静止への切り替え条件と、そこで除く運動エネルギーの扱いを明記する。
- または低速域の力の定義を見直し、静止判定と整合するモデルを選ぶ。
- 解析的な参照モデルと数値上の打ち切りを区別し、どちらを比較対象とするかを明記する。

## I-04：純転がり維持条件と滑り消失条件が混同されている

**対象**：06 の VER-G09「純転がりと滑りの境目」、および 05 §8.2 の境目と移行条件。

**区分**：誤り、または移行時点の曖昧さ。

**問題と理由**：境目の不等式は、接触点速度が既に消失した状態で、必要な静止摩擦を供給できるかを判定する条件である。既に存在する滑りを消失させる条件ではない。両者を同じ時点の条件として扱うと、残留滑りを瞬時に消す処理になる。

構成例は、純転がりを保てない速さから滑りに入り、減速して維持可能な速度域に戻る状態である。速度域の境目を通過すること自体は、接触点速度を瞬時に変える衝撃ではない。

**修正の方向**：

- 純転がりが可能になる条件と、滑りが消失する条件を別々に記述する。
- 移行には両方の成立が必要であることを明記し、境目の通過時刻と状態の移行時刻を混同しない。
- 比較する検証項目も、この二つの判定を区別する。

## I-05：散逸力の追加から別軌道間のエネルギー順序は保証できない

**対象**：06 の VER-G10「抗力の ON/OFF の一貫性」のエネルギー比較、および 05 §8.2 の摩擦・抗力モデル。

**区分**：誤り、およびエネルギーの定義の曖昧さ。

**問題と理由**：抗力が各瞬間に負の仕事をすることは、その軌道に沿う散逸の性質である。抗力の有無で軌道が変わると、滑りの大きさ、摩擦の仕事、並進と回転の間のエネルギー移動も変わる。抗力の仕事だけを追加して二つの軌道を比較することはできない。

構成例は、バックスピンを持ち、抗力を除いた場合に並進と回転の角運動量の寄与が打ち消し合う接地状態である。抗力を加えると外力の力積がこの釣り合いを変えるため、一般の滑り状態を含めた軌道間の一律なエネルギー順序は保証されない。

また、「水平の運動エネルギー」が並進のみを指すのか、水平軸まわりの回転も含むのかが明確でない。摩擦は並進と回転の間でエネルギーを移すため、この区別は必要である。

**修正の方向**：

- 軌道間の大小関係を要求するなら、両軌道が純転がりを保つなど、比較の根拠を示せる構成に範囲を限定する。
- 一般の滑りでは、各軌道について外力と摩擦の仕事に対するエネルギー収支を確認する方針に変更する。
- 比較対象のエネルギーに含める並進・回転成分を定義する。

## I-06：物理的静止とシミュレーション終了の条件が揃っていない

**対象**：05 §8.2「静止した後」、§10.2 の P-19、06 の VER-G04、および VER-G07 の停止に関する用語。

**区分**：曖昧さ、および記述間の不整合。

**問題と理由**：§8.2 はステップ内の状態切り替えと鉛直軸まわりの回転の保持を記述する。P-19 は停止閾値と厳密不等号を説明し、VER-G04 はステップ終了時の停止イベントと鉛直回転がある場合の終了の扱いを定める。しかし、水平運動の静止、全回転を含めた静止、シミュレーション終了が明確に区別されていない。

物理的に速度が消失する条件と、正の数値閾値を下回る条件は異なる。ステップ内の移行時刻と格子上の終了時刻も異なる。これらを区別すれば両立しうるが、改定後の §8.2 だけでは停止閾値の論理条件や終了判定との接続が決まらない。

**修正の方向**：

- 力学状態の静止と、シミュレーションの終了イベントを別々に定義する。
- 閾値の対象となる速度・角速度の成分、条件の論理積・論理和、等号の扱いを明記する。
- ステップ内で状態が変わった後に終了時刻をどう決めるか、鉛直回転を保持する場合に終了できるかを明記する。

## I-07：閉形式の縮退ケースと適用条件の記述が不足

**対象**：05 §8.2「閉形式で解ける」と、その参照先である 06 の VER-G07。

**区分**：曖昧さ、および適用条件の欠落。

**問題と理由**：記載された式は、転がり抵抗係数または抗力係数をゼロにできる仕様の全範囲で、そのまま評価できる形ではない。係数が消えると分母や比が未定義になる場合があり、対応する場合分けが必要である。また、純転がりの式は必要な静止摩擦を供給できる状態に限って適用できる。

停止という用語も、係数の組合せによっては、実際の速度消失と数値閾値による終了を区別して定義する必要がある。適用範囲が未整理のままでは、式を使えない条件での差を積分誤差として扱うおそれがある。

**修正の方向**：

- 係数が正の場合とゼロの場合を区別し、それぞれの参照式の適用範囲を明示する。
- 純転がり維持条件を参照式の前提として明記する。
- 停止時間・距離の用語について、定義の対象と存在条件を明記し、数値閾値による終了と分ける。

## I-08：対象の誤差に対する許容誤差区分の適用範囲が合っていない

**対象**：06 の TOL-A/B/C の定義、VER-G07〜G09 の許容誤差欄、および 05 §8.2 のイベント探索。

**区分**：記述間の矛盾、および誤差評価の条件の不足。

**問題と理由**：TOL-C の定義は適用対象を真空中の接地時刻に限定する一方、転がりのイベントにも参照されている。二分法の打ち切り幅は、数値積分で得たイベント関数に対する探索区間の幅であり、真の運動のイベント時刻に対する誤差全体ではない。

転がりでは、探索誤差に加えて軌道の積分誤差がイベント時刻に影響する。イベント関数の変化が緩やかな場合には時刻への影響が大きくなり、接するだけの根などでは単純な符号反転探索の前提も成立しない。

また、抗力を除いた固定符号の区間での値の比較と、滑り消失・速度反転を含むイベント時刻の比較では誤差の原因が異なる。丸め誤差だけを対象とする TOL-A を、部分刻みの求根を含む比較全体へそのまま適用する根拠は不足している。

**修正の方向**：

- 代数的な値の比較、軌道の積分誤差、イベント探索の誤差を分ける。
- 転がりイベントに TOL-C を拡張するなら、適用対象、根の条件、積分誤差の扱いを同時に定義する。
- 変化が緩やかな根や接する根の扱いを別途定める。許容幅は根拠なく追加せず、誤差の構成と収束に基づいて決める。
