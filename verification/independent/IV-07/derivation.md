## 2. 双線形評価（VER-F15）

### 2.1 閉形式の独立導出

**前提条件**：05 §7.9 の有効な表、有限の $q,s$、物理的定義から $s\ge0$。$q$ のゼロの場合は §8 の質問 Q1 を参照。まず $J,K\ge2$ とする。

端への切り詰め後の点を $(\hat q,\hat s)$ とし、セルの各方向の相対位置を $t,u\in[0,1]$ とする。下辺・上辺それぞれを $q$ 方向に線形補間し、続いて $s$ 方向に補間すると、

\[
C=(1-u)[(1-t)C_{jk}+tC_{j+1,k}]
  +u[(1-t)C_{j,k+1}+tC_{j+1,k+1}].
\]

逆の順でも展開結果は同じ。四つの重みは非負で総和1なので、期待値は四隅の最小・最大の間にある。非負の $C_D$ 表から負の補間値は生まれない（厳密算術）。

**期待値**：格子点では $C_{jk}$、$q=q_j$ の線上では $(1-u)C_{jk}+uC_{j,k+1}$、$s=s_k$ の線上では $(1-t)C_{jk}+tC_{j+1,k}$。中心は四隅の和の $1/4$。内部格子点の左右どちらのセルを選んでも同じ値になる。最終格子点でも端の行・列を使い、存在しない次の点を必要としない。

外側では切り詰めた座標を用いる。$q<q_0$ は最初の行を $s$ で補間し、$q>q_{J-1}$ は最後の行を補間する。$s>s_{K-1}$ は最後の列を $q$ で補間する。「端の値」は他方の座標まで一定にする意味ではない。

**許容誤差・根拠**：数式は厳密、数値出力は A。05 §7.9 の各方向の線形性と端値規則から導出した。

### 3.3 eta と閾値の要求

**前提・期待値**：05 §10.3・04 §6 に従い、有効な力項が Re 依存係数または (Re,S) 表を使うときだけ、$\eta$ は正の有限値として必要。なし（未決定）・0・負数・NaN・±Infinity は `invalid-parameter`。これは厳密なエラー判定であり、06 F17 の力の大きさの A と区別する。

- 抗力表 ON、またはマグヌス表 ON なら必要。$J=1$ でも表という形式であるため要求を免除する規定はない。
- 表を持つ力項がすべて OFF、または有効な係数が定数・S の折れ線だけなら eta は確認しない。
- 初期 $U\le\varepsilon_v$、$\omega=0$、$\rho=0$ は、力項 ON の表に必要な入口検証を免除する規定ではない。
- 飛翔と転がりの抗力が対象（05 §10.3 の明記）。一般の Re 依存 $C_M$ も同節には含まれるが、04 §6 の現在の公開 API では P-22 は定数。今回 $C_M$ の表を新しい API として要求しない。
- P-21 はマグヌス ON、P-23 は対応空力 ON（さらに転がりの条件）、P-24 は §7.5(c) ON のとき、正の有限値を要求。P-21・P-23 の既存値は §10.2 の**仮置き**であり、誤差許容幅ではない。

## 4. Re・S・力の具体例（VER-F17）

**前提条件**：検証用に $R=1/10\ \mathrm m$、$\rho=1\ \mathrm{kg/m^3}$、$\eta=1/100000\ \mathrm{Pa\,s}$、$\mathbf w=0$、$\mathbf v=(10,0,0)\ \mathrm{m/s}$、$\boldsymbol\omega=(0,0,25/2)\ \mathrm{rad/s}$。両力 ON、T を両係数の表に用い、$U>\varepsilon_v$、$|\omega\times\mathbf u|>\varepsilon$。これは05 §10.2 の大気標準値を採用した例ではない。

\[
[\eta]=\mathrm{kg/(m\,s)},\quad
Re=\frac{(1)(10)(2/10)}{1/100000}=200000,
\qquad S=\frac{(1/10)(25/2)}{10}=1/8.
\]

Re は $(\mathrm{kg/m^3})(\mathrm{m/s})(\mathrm m)/(\mathrm{kg/(m\,s)})=1$、S も $\mathrm m\cdot\mathrm{s^{-1}}/(\mathrm{m/s})=1$。rad は無次元。直径 $2R$ と半径 $R$ の取り違えを区別できる。

T04 より $C_D=C_L=7/16$。$A=\pi/100\ \mathrm{m^2}$、$BU^2=\pi/2\ \mathrm N$ なので、

\[
|\mathbf F_D|=|\mathbf F_M|=\frac{7\pi}{32}\ \mathrm N,
\quad \mathbf F_D=(-7\pi/32,0,0)\ \mathrm N,
\quad \mathbf F_M=(0,7\pi/32,0)\ \mathrm N.
\]

**許容誤差・根拠**：Re・S・係数・力の数値評価は A。単位と符号は厳密。05 §7.3・§7.4・§7.6 と §2 の補間から導出。$\hat z\times\hat x=\hat y$。係数を負の $C_L$ にしたときは力が反転し、大きさは $BU^2|C_L|$。

## 5. 表を使っても成立する解析結果

### 5.1 散逸（VER-F03）

**前提条件**：無風、重力と抗力 ON、マグヌス・回転減衰 OFF、地面イベントなし。$m>0$、$\rho\ge0$、有効な非負 $C_D$ 表。S 依存も許す。

**導出・期待値**：$E=m|\mathbf v|^2/2+mgy$ とすると、重力の仕事が位置エネルギー変化と相殺し、

\[
\dot E=\mathbf F_D\cdot\mathbf v=
\begin{cases}-B C_D(Re,S)U^3\le0&U>\varepsilon_v,\\0&U\le\varepsilon_v.\end{cases}
\]

係数の時間微分は現れない。したがって S が速度に伴って変わっても非増加。$C_D=0$ または $\rho=0$ では一定。正の係数・密度・有効速度なら厳密に減少。

**許容誤差**：瞬時仕事率・数値のエネルギー増加判定は A、エネルギー減少量と抗力の仕事積分の差は B（06 F03）。RK4 自体が任意の刻みでエネルギー非増加を保証するわけではない。

**限界**：風があると $\mathbf F_D\cdot\mathbf u\le0$ は保たれるが、$\mathbf F_D\cdot\mathbf v$ は正になり得る。ワールド系エネルギー非増加の前提には無風が必要。

### 5.2 円運動（VER-F05）

**前提条件**：無風、重力・抗力・回転減衰 OFF、球の一定の角速度ベクトル $\boldsymbol\omega=W\hat z$、初速 $\mathbf v(0)=V\hat x$、$W,V>0$、有効な表、両縮退閾値を超える。地面イベントなし。$\rho,m>0$。

**導出**：$\mathbf F_M\cdot\mathbf v=0$ から $|\mathbf v|=V$。力は $\omega$ にも垂直なので直交関係が保たれる。W 一定より $Re_*=\rho V(2R)/\eta$、$S_*=RW/V$ は一定、したがって表の値 $c=C_L(Re_*,S_*)$ も一定（格子線上でもよい）。

\[
\dot{\mathbf v}=\Omega\hat z\times\mathbf v,
\quad \Omega=\frac{BcV}{m},\quad
\mathbf v(t)=V(\cos\Omega t,\sin\Omega t,0),
\]
\[
\mathbf x(t)-\mathbf x(0)=\frac{V}{\Omega}(\sin\Omega t,1-\cos\Omega t,0),
\quad r=\frac{V}{|\Omega|}=\frac{2m}{\rho A|c|}.
\]

**期待値**：$c>0$ で仕様の半径、$c<0$ なら旋回反転、$c=0$ なら直線。§4 の初速・角速度・表、$m=1/2\ \mathrm{kg}$ なら $c=7/16$、$\Omega=7\pi/160\ \mathrm{s^{-1}}$、$r=1600/(7\pi)\ \mathrm m$。

**許容誤差・根拠**：閉形式そのものの評価 A、時間積分との速さ・位置・半径の比較 B（06 F05・F17）。§10.3 の一括入口は $g\ge1$ だが、重力 OFF の条件であり、重力係数を0にして入口範囲を変更する必要はない。

### 5.4 鏡映（VER-F07）

**前提条件**：$Q=\operatorname{diag}(1,1,-1)$ による xy 鏡映。位置・速度・風は $Q$、角速度は軸性ベクトルなので $\omega'=-Q\omega$。同一の表・パラメータ・鏡映対称な地面条件。

**導出・期待値**：ノルム不変より $Re'=Re,S'=S$。表の評価値も等しい。外積の変換則 $(Qa)\times(Qb)=\det(Q)Q(a\times b)$ から

\[
\omega'\times\mathbf u'=Q(\omega\times\mathbf u),
\quad \mathbf F_D'=Q\mathbf F_D,\quad\mathbf F_M'=Q\mathbf F_M.
\]

トルクは軸性なので $\tau'=-Q\tau$。縮退判定もノルムが等しく同じ枝へ進む。よって連続系の解は鏡映される。例として $\mathbf u=(3,0,4)$、$\omega=(0,2,0)$ は $\mathbf u'=(3,0,-4)$、$\omega'=(0,-2,0)$、外積 $(8,0,-6)$ は $(8,0,6)$ に変わる。

**許容誤差・根拠**：06 F07 の A を継承。記号的変換則は厳密。これは二つの計算結果の対称性であり、時間積分の真の解に対する誤差を A とする意味ではない。

## 6. 連続性・滑らかさと RK4（VER-F18）

**前提条件**：有限で有効な表、有限の $q,s\ge0$。まず速度・外積の縮退閾値および地面イベントを横切らない条件。

**導出・期待値**：セル内では $C=a+bq+cs+dqs$。隣接セルは共通辺の二つの値を共有するため、辺上の線形関数が一致する。したがって表は C0 連続。外側の一定延長も境界値を共有し連続。一点方向でも同様。

法線方向の勾配は一般に一致しない。例 T の $s=0,q=300000$ で、左の $\partial C/\partial q=(1/2)/200000=1/400000$、右は $1/400000$ で偶然等しい。しかし $s=1/4$ では左が $(3/4)/200000=3/800000$、右が $(3/4)/400000=3/1600000$ で異なる。従って「不連続になる」は一般的性質であり、常に不連続という意味ではない。全セルが一つの双線形式なら内部格子線で滑らかになり得る。端への一定延長では法線勾配が0になり、端でも通常は折れ曲がる。

**積分への帰結**：有効域でノルム・正規化は滑らか。単一セル内なら表を組み合わせた右辺も滑らかなので、通常の RK4 の局所 $O(h^5)$・大域 $O(h^4)$ の議論が適用できる。一方、格子線通過では右辺は連続でも一般に一次微分が跳び、通常の4次の証明の前提が失われる。

低下し得ることは求積の例で分かる。$y'=|t-t_*|$、1ステップ内で $t_*=t_n+h/4$ とすると、厳密な増分は $5h^2/16$。時刻だけに依存する右辺に RK4 を適用した増分は Simpson 型で

\[
\frac h6\left(\frac h4+4\frac h4+\frac{3h}4\right)=\frac{h^2}3,
\]

差は $h^2/48$。これは格子による微分の折れを模した数学的例で、実際の飛翔が必ず同じ誤差係数になるという主張ではない。有限個の横断で、通過ステップに $O(h^2)$ の欠陥があれば、全体も2次程度に支配され得る。格子線を刻み境界に合わせたり、勾配が一致したり、軌道が接したりする特例では異なる。

**許容誤差・判定**：06 F18 は記録のみ。全軌道へ一律に「2次」または「4次」を要求しない。通過の位相が刻み系列で変わるので、誤差比が一定にならない場合もある。刻み・最終時刻・参照解の精度・通過した線・観測次数・P-18 の刻みでの位置や速度の誤差を単位別に記録する。細刻み参照を使う場合はさらに細分化して参照誤差が比較誤差を支配しないことを確認する。

格子の連続性は、$U=\varepsilon_v$ や $|\omega\times\mathbf u|=\varepsilon$ の打ち切りに起因する力の不連続を取り除かない。F18 はこれらを避け、格子線の影響を分離する。
